# Health AI Model Training

This directory contains scripts to train the health classifier and export model artifacts for both native and web platforms.

## Setup

1. Install Python dependencies:

```bash
pip install tensorflow numpy pandas scikit-learn
```

2. Train with a real labeled export (required for production):

```bash
python train_health_classifier.py
```

Synthetic severity labels are generated by deterministic vital-sign rules
(not random category-only sampling) to improve severity learning.

## Train With Real Data (Option 2)

If you exported labeled records from Firebase (or any JSON file with `symptoms`, `details`, `age`, `ai_category/category`, `ai_severity/severity`), run:

```bash
python train_health_classifier.py --data-file health_data.json
```

Reference format: `train_model/health_data.sample.json`

Synthetic data is not accepted as production evidence. A clearly labeled
non-production demonstration may be run explicitly with
`--allow-synthetic-demo`; synthetic samples must never be used to satisfy the
dataset-size or accuracy requirements:

```bash
python train_health_classifier.py --data-file health_data.json --augment-synthetic 1000 --allow-synthetic-demo
```

You can also tune epochs/batch size:

```bash
python train_health_classifier.py --data-file health_data.json --epochs 30 --batch-size 16
```

Verify that specific keywords are included in feature extraction before training:

```bash
python train_health_classifier.py --verify-keyword "rapid heartbeat" --verify-keyword covid
```

## Generated Files

After training, these files are saved to `../assets/models/`:

1. `health_classifier.tflite` (native/mobile/desktop ML runtime, when conversion succeeds)
2. `health_classifier_weights.json` (portable web ML runtime)
3. `encoders.json` (label metadata)

Both JSON files now include feature metadata used by Flutter runtime:

- `feature_keywords`
- `keyword_hash` (FNV-1a hash bucket config)
- `vital_feature_indices`
- `category_recovery_guidance` (medication/home care/advice fallbacks)

## Web-Compatible ML Path

Flutter Web cannot use native `tflite_flutter` runtime directly. This project uses a portable JSON-weights model for web inference.

- Web runtime file: `assets/models/health_classifier_weights.json`
- Auto-loaded by: `lib/app/core/services/health_ai_classifier.dart`
- If missing or invalid: app falls back to rule-based classification

## Flutter Integration

Ensure your `pubspec.yaml` includes:

```yaml
flutter:
  assets:
    - assets/models/
```

## Troubleshooting

If web still shows rule-based mode:

1. Confirm `assets/models/health_classifier_weights.json` exists.
2. Confirm `assets/models/` is included in `pubspec.yaml`.
3. Re-run training and refresh the web app.
